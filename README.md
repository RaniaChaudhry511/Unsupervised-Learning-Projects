# Unsupervised-Learning

Unsupervised machine learning projects built in Google Colab.

## Projects

- **K-Means Clustering:**
-  groups data into clusters (`K_means_clustering_project.ipynb`)
-  
- **Hierarchical Clustering:**
-  builds clusters using a dendrogram (`HIERARCHIAL_CLUSTERING.ipynb`)
-  
- **PCA:**
-  reduces the number of features while keeping most of the information (`PCA_project.ipynb`)

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib

## How to Run
Open any notebook in Google Colab and run all cells.
